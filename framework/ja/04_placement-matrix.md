## 4. 振り分けチェックリスト

- [ ] すべての `REQ-` が、少なくとも1つの層に振り分けられている
- [ ] 同じ定義・ルールが2つ以上の層に書かれていない
- [ ] `APP-` の要件が、業務ルールや指標の計算式を自分で持っていない（参照している）
- [ ] AI のプロンプトに書く予定の内容が、`ONT-` / `SEM-` の参照だけになっている
- [ ] 閲覧権限は `POL-` で定義され、1件の問い合わせや AI エージェント経由も含め、すべての経路で同じ権限が効く
- [ ] 合計点が境界（8〜9点）の要件と、フローと点数が食い違った要件は、判断理由が書かれている
- [ ] すべての `ONT-` / `SEM-` に決定権者が書かれている
- [ ] `ONT-` は後ろの要素から前の要素への参照だけで書かれている（逆向きの参照がない）
- [ ] すべての `SEM-` が、数える対象の `ONT-` を参照している
- [ ] 1件の判定に使う値も含め、データの読み取りはすべて `SEM-` の定義を通している（AI やアプリがデータ層に直接クエリを書かない）
- [ ] 状態（STA）には時点の定義が、アクション（ACT）には AI への許可が書かれている
