# 03. ヒアリングガイド

> 業務担当者へのヒアリングで使う質問リストです。AI で実装が速くなるほど、要件定義の工数はヒアリングに寄っていきます。各層の質問を一通り聞くと、要件を振り分けるのに必要な材料がそろうように並べています。
>
> 進め方：最初に「0. 全体」を聞き、出てきた業務用語や数字ごとに 1〜4 を深掘りします。回答はそのまま [04 振り分けマトリクス](04_placement-matrix.md) の「元の要望」欄に書き写します。

## 0. 全体

| No | 質問 | 聞く理由 |
|---|---|---|
| G-01 | この業務で、最終的に誰が何を判断していますか | 判断に使う概念と数字を洗い出す起点 |
| G-02 | その判断のために、今どの資料・画面・数字を見ていますか | 既存の定義（の散らばり方）を把握する |
| G-03 | 判断を誤ったとき、何が起きますか | 「ブレたときの影響」の点数の根拠 |
| G-04 | AI に任せたい作業・任せたくない作業は何ですか | アプリ / AI 層の範囲と、AI が参照する定義の洗い出し |

## 1. オントロジー層（業務の概念・関係・ルール）

> [06 オントロジー設計ガイド](06_ontology-design.md) の参照順（語彙 → 構造 → 状態と事象 → ルール → アクション）に沿って聞きます。言葉が揃う前にルールを議論しないのがコツです。

| No | 要素 | 質問 | こんな答えが出たら |
|---|---|---|---|
| O-01 | VOC | 業務でよく使う言葉を挙げてください。同じものを別の呼び方をしていませんか | 用語と同義語の候補 |
| O-02 | VOC | その言葉は部署によって意味が違いますか | 違うなら、正式な定義を決めるか、別の概念として分ける（最重要） |
| O-03 | VOC | 「〇〇」に含まれないのはどんな場合ですか | 反例。AI の誤解を減らすのにいちばん効く |
| O-04 | STR | 業務で扱う「モノ」は何ですか。それぞれ、何をもって1件と数えますか | エンティティと、一意になる条件 |
| O-05 | STR | 〇〇と△△はどういう関係ですか。1対多ですか | 関係と多重度 |
| O-06 | STA | 〇〇にはどんな状態がありますか。何が起きると変わりますか | 状態と事象。例外的な遷移（差し戻し、復活）も聞く |
| O-07 | STA | 「今の状態」とは、いつ時点のことですか（当日、前日末、月末） | 時点の定義 |
| O-08 | RUL | 「必ずこうなっていないといけない」ルールはありますか。誰が決めましたか | 業務ルールと決定権者 |
| O-09 | RUL | そのルールが変わったのは、前回いつですか | 変更頻度と有効期間 |
| O-10 | ACT | 誰が、どんな条件のときに、何を変更・処理していますか | アクションの実行者・前提条件・結果 |
| O-11 | ACT | その処理を AI に任せてよいですか（自動 / 人が確認してから / 任せない） | AI への許可 |

## 2. セマンティック層（数字の定義）

| No | 質問 | こんな答えが出たら |
|---|---|---|
| S-01 | よく見る数字を挙げてください | 指標の候補 |
| S-02 | その数字は、何を足して・何を除いて・何で割っていますか | 計算式。税込 / 税抜、キャンセルの扱い、返品の扱いなど |
| S-03 | 「今月」とはいつからいつまでですか | 期間定義（暦月 / 会計月 / 締め日） |
| S-04 | その数字をどんな切り口で見ますか（地域別、担当別…） | 集計軸と粒度 |
| S-05 | 同じ名前で、部署ごとに違う数字が出ていませんか | 定義の分裂。統一するか、別名の指標として分けるか |
| S-06 | その数字を見てよい人・見てはいけない人は誰ですか | 行・列レベルの権限。AI 経由の閲覧も含めて確認する |

## 3. データ層（ソース・品質・鮮度）

| No | 質問 | こんな答えが出たら |
|---|---|---|
| D-01 | そのデータは、どのシステム・誰の入力から来ていますか | ソースと入力責任者 |
| D-02 | どれくらい新しいデータが必要ですか（リアルタイム、前日、月次） | 取り込み頻度 |
| D-03 | データが間違っていたり、抜けていたりすることはありますか | 品質ルールの候補 |
| D-04 | 過去の状態（変更前の値）を見たいことはありますか | 履歴の持ち方 |
| D-05 | いつまで残す必要がありますか。消さないといけないデータはありますか | 保持期間、個人情報の扱い |

## 4. アプリ / AI 層（見せ方・操作・AI の振る舞い）

| No | 質問 | こんな答えが出たら |
|---|---|---|
| A-01 | 誰が、どのタイミングで、どの端末で使いますか | 利用シーン |
| A-02 | 一目で分かってほしいことは何ですか | 画面の優先順位、強調表示 |
| A-03 | 今いちばん手間がかかっている操作は何ですか | 自動化・AI 化の候補 |
| A-04 | AI の回答に、根拠として何が示されていれば信用できますか | 参照元の提示方法。参照先は下の層の定義であるべき |
| A-05 | AI が間違えたとき、誰がどう気づいて直しますか | 人による確認ポイント、エージェントの権限範囲 |

## ヒアリング中に注意するサイン

| サイン | 意味 | 次に聞くこと |
|---|---|---|
| 同じ言葉を人によって違う意味で使っている | オントロジーが未定義 | O-02、O-03、O-08 |
| 「この画面の数字は、あの資料と少し違う」 | セマンティック層の定義が分裂している | S-02、S-05 |
| 「毎回 Excel で手直ししてから使う」 | データ層の品質問題をアプリ側で吸収している | D-03 |
| 「AI にはこう指示している」と業務ルールを語る | ルールがプロンプトに埋まっている | O-08 で正式なルールとして取り出し、AI に任せる範囲は O-11 で確認する |
| 「とりあえず画面に出してほしい」 | 定義が決まらないまま見せ方の話になっている | S-01〜S-03 に戻る |
